# Orkestra — Your Smart Home Brain + Gateway

**Orkestra is a unified, intelligent Brain + Gateway for your smart home** — one beautiful dashboard, natural-language control, and native Home Assistant automations, all running inside your HA instance.

## ✨ Key Features

- **Natural-language AI chat** — Control devices, ask questions, and draft automations in plain English. Orkestra turns your intent into real Home Assistant actions.
- **Modern, auto-generated UI** — A minimalist dashboard with glassmorphism design, organized by rooms and zones from your existing entities — no manual layout required.
- **Smart native automations** — Real-time state analysis powers intelligent suggestions and deployable HA automations, so your home learns how you actually live.

## 🚀 Getting Started

1. Click **Install** and start the add-on.
2. Open the **Configuration** tab and enter your **Orkestra Cloud** credentials:
   - **Orkestra Cloud URL** — defaults to `https://api.orkestra-assistant.com`
   - **Orkestra Instance Token** — from your [Orkestra Cloud](https://orkestra-client.vercel.app) account
3. Save, restart the add-on if prompted, then open **Orkestra** from the Home Assistant sidebar.

Home Assistant API access is configured automatically — no long-lived access token required for normal add-on use.
