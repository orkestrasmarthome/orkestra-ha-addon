# Orkestra

**Intelligent Smart Home AI Dashboard & Local Gateway for Home Assistant**

</div>

Orkestra is a unified brain + gateway for your Home Assistant instance — a modern dashboard, natural-language control, and native automations, running locally with a secure cloud relay when you are away.

## Getting started

1. Click **Install**. New installs default to **Start on boot**.
2. **Start** the add-on, then click **Open Web UI** (or open **Orkestra** in the Home Assistant sidebar).
3. Copy the **pairing code** shown in the setup wizard.
4. Sign in at [orkestra-assistant.com](https://orkestra-assistant.com), create or select a home, and enter the code to link this instance.

> **Tip:** Home Assistant API access is configured automatically — no long-lived access token is required for normal use.

> **Auto-update** is a Home Assistant preference. Supervisor does not allow add-ons to enable it by default — turn it on in the add-on info page if you want automatic upgrades.

## Key features

- **Local-first execution** — LAN fast-path when you are at home.
- **AI-driven automations** — Chat that turns intent into Home Assistant actions.
- **Unified media & climate** — Rooms, playback, and climate in one dashboard.
- **Secure outbound cloud relay** — Access from the web portal or mobile app without opening inbound ports.
